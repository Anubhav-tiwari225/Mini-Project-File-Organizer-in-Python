# File Organizer in Python

A lightweight Python script that automatically organizes files in a directory into categorized subfolders based on their file extensions (e.g., Images, Documents, Videos, Audio, Archives).

---

## 📌 Features

- **Automatic Categorization:** Groups files into dedicated folders (`Images`, `Documents`, `Audio`, `Videos`, `Archives`, etc.).
- **Unrecognized Files Support:** Automatically moves unknown file types to an `Others` folder.
- **Safe Execution:** Skips directories and existing folders to prevent accidental nesting.
- **Cross-Platform:** Works on Windows, macOS, and Linux.
